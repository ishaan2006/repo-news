Repo News ranks GitHub repositories by stars gained in the chosen window, counted from GitHub's own star timestamps. The short windows (12h to 3d) refresh every hour and 7d/14d every 6 hours. The longer windows (1mo, 3mo, 1y, YTD) refresh when the site owner runs an update, and show their "as of" date. Repos created inside a window count every star they have. A number with a "+" is a minimum: very large repos are only counted back so far. new shows repos created recently. Categories are tagged by Claude Haiku from each repo's name, description and topics. Obvious spam (cracked-software lures, star-farmed repos with no forks) is filtered out.
