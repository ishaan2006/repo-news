hot works like the Hacker News front page: each day's new stars count, divided by how old they are, stars / (age_hours + 2)^1.8, summed over the last two weeks. A repo climbing right now beats one that peaked last week.

today, 3d … YTD rank by plain stars gained in that window, counted from GitHub's daily star history. GitHub only publishes whole days, so "today" is the latest day it has data for. Hot and today through 3mo refresh hourly; 1y and YTD refresh when the site owner runs an update and show their date.

new shows repos created recently. Categories are tagged by Claude Haiku from each repo's name, description and topics. Obvious spam (cracked-software lures, star-farmed repos) is filtered out.
